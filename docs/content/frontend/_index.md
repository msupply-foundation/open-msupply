# Frontend

The open-mSupply frontend rewrite, built with [SolidJS](https://www.solidjs.com/).

## UI showcase

The component library has a live showcase — every component in the library,
rendered, with the variants and states each one supports.

**[Open the UI showcase →](/showcase/)**

It is published from the same build as this site, so it tracks whatever is on
`develop` at the last deploy. Sections are linkable: append the section id to
the hash, for example
[`/showcase/#/showcase/buttons`](/showcase/#/showcase/buttons).

The showcase needs no server and no login — it renders the library in
isolation, with no data from a real site.
